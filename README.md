# Телеграм-бот для практики языка и вопросов
Этот проект представляет собой Telegram-бот, который помогает пользователям практиковать язык с помощью голосовых заданий, получения обратной связи и общения с менеджером. Бот поддерживает голосовые и текстовые сообщения, транскрибирует голосовые ответы, предоставляет задания в аудио формате, а также позволяет задавать вопросы менеджеру.
---
## Основные функции
- **Практика английского языка:**
  - Генерация голосовых заданий для пользователя.
  - Получение голосовых ответов, транскрипция и автоматическая обратная связь.
- **Общение с менеджером:**
  - Пользователи могут задавать вопросы менеджеру через команду /help и кнопку «Задать вопрос».
  - Вопросы сохраняются в базу данных.
- **Информация и помощь:**
  - Команда /help предоставляет список часто задаваемых вопросов и инструкций.
---
## Требования
- Python 3.8+
- Установленные библиотеки:
  - aiogram
  - sqlite3 (часть стандартной библиотеки)
  - ffmpeg (для обработки аудио)
  - openai (если используется API OpenAI)
  - Другие необходимые библиотеки, указанные в `requirements.txt` (если есть)
---
## Настройка базы данных
База данных создается автоматически при первом запуске. В `main.py` есть функция `ensure_db()`, которая создаст таблицы (`users`, `user_messages`).
---

## Запуск бота
```bash
python main.py
```

Бот запустится и будет готов к использованию.
---

## Использование
- Введите команду `/practice` для начала практики.
- Следуйте инструкциям для отправки голосового ответа.
- Используйте команду `/help` для получения справочной информации.
- Нажмите кнопку "Задать вопрос", чтобы задать вопрос менеджеру.
---

## Структура проекта
- `main.py` — основной файл запуска бота.
- `ai_service.py` — модуль с функциями для взаимодействия с AI (генерация заданий, обратная связь, FAQ).
- `transcrib_voice.py` — модуль для транскрибирования аудио.
- `keyboard.py` — создание клавиатур для взаимодействия.
- `config.py` — конфигурационные параметры.
- `data/db.sqlite3` — база данных (создается автоматически).
---

## Важные примечания
- Убедитесь, что у вас установлен ffmpeg, и путь к нему указан правильно.
- Для работы голосовых функций необходим API-ключ OpenAI или другой сервис для транскрибирования.
- Обратите внимание на ограничение по размерам файлов и лимиты API.
